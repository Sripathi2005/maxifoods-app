Fasting Window Impact Summary

During Shravan (August) and Navratri (April & October), customer ordering patterns shift significantly towards vegetarian items.

Key Finding: Flexitarian customers order vegetarian items just 27.7% of the time during regular weeks, but jump to 76.9% during fasting windows — justifying stocking higher inventory of Paneer, Biryani side dishes, and sweets.

Relational Data Warehouse — Star Schema Architecture

Dimensional 3NF Star Schema centered around FACT_ORDERS (50,060 order rows) and FACT_ORDER_ITEMS (102,430 line items) linked to 4 dimension tables.

50,060 Fact Orders 4 Dimension Tables
DIM_CUSTOMER Dimension
  • 🔑 customer_id (PK) INTEGER
  • customer_name VARCHAR
  • city VARCHAR
  • diet_profile VARCHAR
1 : N ➔ FACT_ORDERS (customer_id)
FACT_ORDERS (Central) Fact Table
  • 🔑 order_id (PK) INTEGER
  • 🔗 customer_id (FK) DIM_CUSTOMER
  • 🔗 restaurant_id (FK) DIM_RESTAURANT
  • 🔗 order_date (FK) DIM_TIME
  • final_amount (Measure) DECIMAL
  • is_veg_order BOOLEAN
  • rating_given FLOAT
DIM_RESTAURANT Dimension
  • 🔑 restaurant_id (PK) INTEGER
  • restaurant_name VARCHAR
  • city VARCHAR
  • primary_cuisine VARCHAR
  • avg_rating FLOAT
1 : N ➔ FACT_ORDERS (restaurant_id)
DIM_TIME Dimension
  • 🔑 date (PK) DATE
  • day_of_week VARCHAR
  • month_name VARCHAR
  • veg_season_tag VARCHAR
1 : N ➔ FACT_ORDERS (order_date)
FACT_ORDER_ITEMS Line Item Fact
  • 🔑 order_item_id (PK) INTEGER

End-to-End System & Data Flow Workflow

Visual representation of how data flows seamlessly from raw transactional logs to real-time interactive user recommendations and owner analytics.

1

Raw Swiggy Dataset Ingestion

Tool: Python Pandas CSV Ingestion

What We Implemented: Ingested 50,060 raw order records across Chennai subcities, capturing order timestamps, dish quantities, discounts, and customer ratings.

2

Python ETL & Data Preprocessing

Tool: Python scripts/process_swiggy_chennai_dataset.py

What We Implemented: Sanitized missing values, normalized multi-valued cuisine strings, tagged 236 egg dishes vs pure veg items, and mapped order timestamps across all 12 months (Jan–Dec 2025).

3

Star-Schema Relational Data Warehouse

Tool: PostgreSQL 15 Relational Database

What We Implemented: Structured a 3NF Star-Schema (`FACT_ORDERS`, `FACT_ORDER_ITEMS`, `DIM_RESTAURANT`, `DIM_CUSTOMER`, `DIM_FOOD_ITEM`, `DIM_TIME`) with foreign key constraints & indexes for sub-millisecond query performance.

4

Apriori & K-Means Machine Learning Engines

Tool: Mlxtend v0.22 + Scikit-Learn KMeans

What We Implemented: Extracted frequent itemset association rules (Support, Confidence, Lift) and clustered 2,170 customers into 4 RFM segments (*Loyal High-Spenders, Steady Regulars, New/Occasional, At Risk*).

5

FastAPI Asynchronous Backend REST APIs

Tool: Python FastAPI + Uvicorn Async Server

What We Implemented: Built secure, async REST endpoints (`/api/recommendations`, `/api/restaurants/analytics`, `/api/datamining`) exposing clean JSON models for real-time frontend consumption.

6

Single-Page SaaS Analytics Dashboard & PDF Generator

Tool: Vanilla HTML5 / CSS3 + Chart.js v4

What We Implemented: Built a responsive single-page Web Application rendering customer recommendations, cuisine-distinct owner polar charts, interactive dish association inspectors, and printable executive PDF downloads.
